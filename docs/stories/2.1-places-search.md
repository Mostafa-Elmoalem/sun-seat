# Story 2.1: قاعدة بيانات الأحياء والمناطق المصرية والبحث التلقائي الهجين (Places & Neighborhoods Autocomplete)

- **الملحمة (Epic)**: Epic 2 - دليل المواقف ومسارات الخطوط الجغرافية
- **جلسة التطوير المقابلة**: 08-dev-geo-routing
- **الحالة**: مسودة معتمدة (Draft / Ready for Dev)
- **الاعتماديات**: لا يوجد

---

## 1. قصة المستخدم (User Story)
كراكب، أريد البحث عن أي حي أو منطقة أو مدينة أو موقف بالعامية أو الفصحى (مثل: "الدقي"، "مصر الجديدة"، "المعادي"، "مدينة نصر"، "أكتوبر"، "سموحة"، "طنطا"، "عبود")، أو تحديد مكاني بنقرة واحدة ("📍 موقعي الحالي")، بحيث تظهر الاقتراحات في أقل من 50ms من الذاكرة المحلية، مع استخدام OpenStreetMap Photon المجاني كبديل مرن لأي موقع فرعي غير مسجل.

---

## 2. معايير القبول (Acceptance Criteria)

- **AC-1 (تغطية الأحياء والمناطق الرئيسية محلياً)**:
  - *Given* ملف `public/data/places.json`.
  - *Then* يغطي ما لا يقل عن 300 حي ومدينة ومنطقة وموقف في مصر (مثل أحياء القاهرة والجيزة والإسكندرية وعواصم المحافظات).
  - *And* حجم الملف الكلي أقل من **25 KB gzipped**.
- **AC-2 (البحث الذكي وتطبيع الحروف)**:
  - *Given* كتابة أحرف بحث مثل "دق" أو "مصر" أو "معاد".
  - *When* يتم استدعاء دالة `searchPlaces(query)`.
  - *Then* تظهر نتائج "الدقي"، "مصر الجديدة"، "المعادي" في أقل من 5ms محلياً بدون شبكة.
- **AC-3 (زر موقعي الحالي - GPS One-Tap)**:
  - *Given* نقر المستخدم على زر "📍 موقعي الحالي".
  - *When* يستجيب متصفح الموبايل بإحداثيات الـ GPS.
  - *Then* يتم تحديد أقرب حي أو منطقة مسجلة في ثوانٍ وتعيينها كنقطة انطلاق.
- **AC-4 (البديل السحابي المجاني - OSM Photon Fallback)**:
  - *Given* كتابة مكان فرعي جداً غير موجود في الملف المحلي (مثل اسم شارع معين).
  - *When* لا توجد نتائج محلية بعد 3 أحرف.
  - *Then* يتم الاستعلام بهدوء من Photon API المجاني (`photon.komoot.io`) لإحضار الإحداثيات وتخزينها في الكاش.

## 3. مقتطفات المعمارية ودوال المعالجة (Dev Context)

### أ. بنية عنصر المكان والحي (`Place` Schema):
```typescript
export interface Place {
  id: string;               // "giza-dokki", "cairo-heliopolis"
  nameAr: string;           // "الدقي", "مصر الجديدة"
  nameEn: string;           // "Dokki", "Heliopolis"
  governorateAr: string;    // "الجيزة", "القاهرة"
  aliases: string[];        // ["الدقي ميدان المساحة", "مصر الجديده روكسي الكوربة"]
  location: { lat: number; lng: number };
  type: 'district' | 'station' | 'city';
  isPopular: boolean;       // للمقترحات السريعة
}
```
