## 1. قصة المستخدم (User Story)
كراكب معجب بالنتيجة، أريد توليد بطاقة مصورة فخمة للمشاركة على واتساب أو إنستجرام ستوري بضغطة زر واحدة عبر متصفحي محلياً (Native HTML Canvas) بدون أي سيرفرات سحابية وبدون تأخير، لتشجيع انتشار التطبيق بالتزامن مع فيديو اليوتيوب.

---

## 2. معايير القبول (Acceptance Criteria)

- **AC-1 (التوليد المحلي عبر Canvas API)**:
  - *Given* النقر على زر "شير النتيجة 📤".
  - *When* يتم استدعاء دالة `generateShareCard`.
  - *Then* يتم رسم الصورة عبر HTML Canvas محلياً في أقل من **200 ميلي ثانية**.
- **AC-2 (محتوى وتصميم الكارت المصور)**:
  - *Then* تحتوي الصورة على:
    - الشعار: **اقعد فين؟ ☀️** (دليل الهروب من شمس المواصلات).
    - مسار الرحلة والوقت ونوع المركبة (مثل: **الدقي ➔ التجمع الخامس**).
    - التوجيه الضخم: **"اقعد شمال!"** مع نسبة الظل 85%.
    - رسم إيزوميتري مصغر ومبهج للسيارة يوضح الكراسي المظللة.
- **AC-3 (المشاركة المباشرة عبر Web Share API)**:
  - *Given* متصفح هاتف يدعم `navigator.share`.
  - *When* يكتمل التوليد.
  - *Then* تفتح نافذة المشاركة الأصلية للموبايل لإرسال الصورة مباشرة لواتساب مع خيار التنزيل المباشر كصورة PNG.

---

## 3. مقتطفات المعمارية والـ Canvas (Dev Context)

```typescript
export async function generateShareCard(result: TripVerdictResult, tripInfo: TripInfo): Promise<Blob> {
  const canvas = document.createElement('canvas');
  canvas.width = 1080;
  canvas.height = 1920; // نسبة 9:16 للستوري
  const ctx = canvas.getContext('2d')!;

  // خلفية متدرجة فخمة
  const gradient = ctx.createLinearGradient(0, 0, 0, 1920);
  gradient.addColorStop(0, '#0F172A');
  gradient.addColorStop(1, '#1E293B');
  ctx.fillStyle = gradient;
  ctx.fillRect(0, 0, 1080, 1920);

  // رسم النصوص والقرار والنسب...
  return new Promise((resolve) => canvas.toBlob((b) => resolve(b!), 'image/png'));
}
```
