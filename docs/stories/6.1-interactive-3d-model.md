# Story 6.1: المجسم ثلاثي الأبعاد التفاعلي ومدار الشمس (Interactive 3D Vehicle & Solar Orbit)

- **الملحمة (Epic)**: Epic 6 - العرض المجسم 3D التفاعلي
- **جلسة التطوير المقابلة**: 11-dev-3d-view
- **الحالة**: مكتمل (Done)
- **الاعتماديات**: Story 4.2

---

## 1. قصة المستخدم (User Story)
كمستخدم ومشاهد لفيديو اليوتيوب، أريد استعراض مجسم 3D عصري وأنيق ("تطبيق فشيخ") للميكروباص/الأتوبيس مع مسار الشمس الكروي وإضاءة وظلال حية تتفاعل باللمس ودوران 360°، بحيث يُحمل المشهد تدريجياً وبذكاء (Dynamic Lazy Import) دون أن يثقل الحزمة الأولية للراكب في الموقف.

---

## 2. معايير القبول (Acceptance Criteria)

- **AC-1 (العزل التام عن الحزمة الأولية Zero Critical-Path Cost)**:
  - *Given* فتح شاشة النتيجة الأولية.
  - *Then* يكون حجم مكتبات Three.js / R3F صفراً في حزمة الـ JavaScript الأولية.
  - *When* يتم التبديل لعرض الـ 3D.
  - *Then* يتم استدعاء الـ Chunk الخاص بالـ 3D بحجم خفيف ومضغوط.
- **AC-2 (موديل 3D عصري وأنيق Stylized & Smooth)**:
  - *Given* ملف الموديل `public/models/microbus-14.glb`.
  - *Then* يكون تصميمه عصرياً وناعماً (Stylized Low-Poly) بحجم أقل من **80 KB** مضغوطاً بـ Meshopt / Draco.
- **AC-3 (الإضاءة والظلال الحية المتفاعلة مع الشمس)**:
  - *Given* زاوية سمت وارتفاع الشمس اللحظية.
  - *Then* يتحرك مصدر الضوء الاتجاهي (DirectionalLight) وكرة الشمس على مدار كروي حقيقي حول السيارة، مسقطاً ظلالاً ناعمة على الجانب المعاكس.
- **AC-4 (التحكم باللمس OrbitControls)**:
  - *Given* لمس الشاشة بإصبع واحد.
  - *Then* تدور السيارة بسلاسة 360° مع إمكانية التكبير والتصغير وتثبيت الأفق، مع احترام تفضيلات `prefers-reduced-motion`.

## 3. مقتطفات المعمارية و R3F (Dev Context)

```tsx
import { Canvas } from '@react-three/fiber';
import { OrbitControls, useGLTF } from '@react-three/drei';

export default function VehicleCanvas({ azimuthDeg, elevationDeg }: Props) {
  // حساب موضع الشمس في فضاء الـ 3D:
  const radius = 10;
  const phi = (90 - elevationDeg) * (Math.PI / 180);
  const theta = (azimuthDeg - 90) * (Math.PI / 180);
  const sunX = radius * Math.sin(phi) * Math.cos(theta);
  const sunY = radius * Math.cos(phi);
  const sunZ = radius * Math.sin(phi) * Math.sin(theta);

  return (
    <div className="h-64 w-full rounded-3xl overflow-hidden bg-gradient-to-b from-sky-400/20 to-slate-900/10">
      <Canvas camera={{ position: [4, 3, 5], fov: 45 }}>
        <ambientLight intensity={0.6} />
        <directionalLight position={[sunX, sunY, sunZ]} intensity={1.8} castShadow />
        {/* كرة الشمس المرئية */}
        <mesh position={[sunX, sunY, sunZ]}>
          <sphereGeometry args={[0.4, 16, 16]} />
          <meshBasicMaterial color="#F59E0B" />
        </mesh>
        <MicrobusModel />
        <OrbitControls enableZoom={false} maxPolarAngle={Math.PI / 2.1} />
      </Canvas>
    </div>
  );
}
```
