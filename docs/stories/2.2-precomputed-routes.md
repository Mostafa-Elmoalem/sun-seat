## 1. قصة المستخدم (User Story)
كمطور، أريد مسترجع مسارات هجين في `src/adapters/routes-repository.ts` يجلب ملفات المسارات المسبقة للخطوط الحيوية فوراً من الـ CDN المحلي، وفي حال طلب مسار بين حيين مخصصين (مثل: الدقي ➔ التجمع الخامس، أو مصر الجديدة ➔ المعادي)، يقوم بطلب خط السير الحقيقي مجاناً عبر Open Source Routing Machine (OSRM API) وتخزينه في الكاش المحلي للموبايل.

---

## 2. معايير القبول (Acceptance Criteria)

- **AC-1 (المسارات المسبقة للخطوط الأكثر شعبية)**:
  - *Given* رحلة شائعة (مثل القاهرة ↔ الإسكندرية أو عبود ↔ طنطا).
  - *When* يتم استدعاء `getRoute(origin, dest)`.
  - *Then* يتم جلب ملف الـ JSON المسبق من الـ CDN في أقل من 50ms وبحجم < 20KB.
- **AC-2 (المسار الحي المجاني للأحياء المخصصة عبر OSRM)**:
  - *Given* مسار بين نقطتين مخصصتين (مثل الدقي ➔ مصر الجديدة أو أكتوبر).
  - *When* لا يتوفر ملف مسبق.
  - *Then* يطلب النظام المسار من OSRM المجاني (`router.project-osrm.org`)، ويسترجع الـ Polyline الفعلي والمسافة بدقة، ويحفظه في كاش المتصفح للعمل أوفلاين لاحقاً.
- **AC-3 (الخط المستقيم التقديري عند انقطاع النت تماماً)**:
  - *Given* طلب مسار غير مسبق في وضع عدم الاتصال (Offline).
  - *When* يفشل طلب الـ OSRM.
  - *Then* يتم توليد مسار مستقيم مباشر (Great Circle Vector) مع شارة *"مسار تقريبي (خط مباشر)"*.

## 3. مقتطفات المعمارية ودوال الجلب (Dev Context)

```typescript
export async function getRoute(origin: Place, dest: Place): Promise<RouteResult> {
  const routeId = `${origin.id}-${dest.id}`;
  
  // 1. فحص الكاش والملفات الثابتة المسبقة أولاً
  const staticRoute = await fetchStaticRoute(routeId);
  if (staticRoute) return staticRoute;

  // 2. فحص كاش المتصفح المحلي
  const cached = await getLocalCache(routeId);
  if (cached) return cached;

  // 3. Fallback للـ OSRM المجاني
  try {
    const osrmUrl = `https://router.project-osrm.org/route/v1/driving/${origin.location.lng},${origin.location.lat};${dest.location.lng},${dest.location.lat}?overview=simplified&geometries=polyline`;
    const res = await fetch(osrmUrl, { signal: AbortSignal.timeout(3000) });
    const data = await res.json();
    const result = {
      encodedPolyline: data.routes[0].geometry,
      distanceKm: data.routes[0].distance / 1000,
      carDurationMin: Math.round(data.routes[0].duration / 60)
    };
    saveLocalCache(routeId, result);
    return result;
  } catch {
    // 4. خط مستقيم أوفلاين
    return generateStraightLineRoute(origin, dest);
  }
}
```
