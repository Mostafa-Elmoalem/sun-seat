# Story 4.3: شريط وقت الشمس التفاعلي والدرج التعليمي الفلكي (Solar Scrubber & Educational Drawer)

- **الملحمة (Epic)**: Epic 4 - واجهة المستخدم وتجربة الموقف السريعة
- **جلسة التطوير المقابلة**: 10-dev-ui-input-results
- **الحالة**: مسودة معتمدة (Draft / Ready for Dev)
- **الاعتماديات**: Story 4.2

---

## 1. قصة المستخدم (User Story)
كمستخدم ومشاهد للفيديو، أريد شريط تمرير وقت تفاعلي (Solar Time Scrubber) أسفل العربية يتيح لي تحريك الوقت من بداية الرحلة لنهايتها ومشاهدة حركة الشمس والظل في الوقت الفعلي (Real-time 60fps)، بالإضافة إلى درج تعليمي ("شوف حسبناها إزاي") يفسر العلاقة الهندسية بين الجغرافيا والفلك بأسلوب ممتع.

---

## 2. معايير القبول (Acceptance Criteria)

- **AC-1 (شريط الوقت الحي 60fps Solar Scrubber)**:
  - *Given* رحلة تستغرق ساعتين (من 02:30 م إلى 04:30 م).
  - *When* يسحب المستخدم المؤشر بإصبعه على طول الشريط الزمني.
  - *Then* تتحدث زاوية الشمس وتوزيع الظل على الكراسي لحظياً بسرعة 60 إطاراً في الثانية.
  - *And* يوضح الشريط النقاط التي تنقلب عندها الشمس من جانب لآخر إن وجدت.
- **AC-2 (الدرج التعليمي الجغرافي "شوف حسبناها إزاي")**:
  - *Given* النقر على زر "💡 شوف حسبناها إزاي (فلك وجغرافيا)".
  - *When* ينفتح الدرج السفلي (Bottom Sheet).
  - *Then* يعرض رسماً مبسطاً للبوصلة الجغرافية يوضح زاوية مسار الطريق (مثلاً 315° شمال غرب) مقابل زاوية سمت الشمس وارتفاعها، مع رابط فيديو اليوتيوب.

---

## 3. مقتطفات المعمارية والمكونات (Dev Context)

```tsx
export function SolarTimeScrubber({ timeline, currentIndex, onChange }: ScrubberProps) {
  const currentStep = timeline[currentIndex];
  return (
    <div className="rounded-2xl bg-white p-4 shadow-sm border border-slate-100">
      <div className="flex justify-between text-xs font-bold text-slate-700 mb-2">
        <span>🕒 حرك الوقت وشوف الشمس بتلف إزاي:</span>
        <span className="text-amber-600">{currentStep.timeCairo}</span>
      </div>
      <input
        type="range"
        min={0}
        max={timeline.length - 1}
        value={currentIndex}
        onChange={(e) => onChange(Number(e.target.value))}
        className="w-full accent-amber-500 h-2 bg-slate-200 rounded-lg cursor-pointer"
      />
    </div>
  );
}
```
