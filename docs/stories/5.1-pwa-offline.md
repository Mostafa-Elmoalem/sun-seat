## 1. قصة المستخدم (User Story)
كراكب يقف في موقف ضعيف التغطية أو منعدم الشبكة في مصر، أريد أن يفتح التطبيق فوراً حتى لو انقطع النت بعد زيارتي الأولى، بحيث تعمل حقول البحث وقاعدة بيانات الأماكن وحسابات الظل بالكامل دون ظهور شاشة الديناصور.

---

## 2. معايير القبول (Acceptance Criteria)

- **AC-1 (التخزين المسبق للـ App Shell)**:
  - *Given* زيارة سابقة للموقع وتفعيل Service Worker.
  - *When* يتم قطع الاتصال بالإنترنت تماماً (وضع الطيران Airplane Mode) وإعادة فتح الموقع.
  - *Then* يفتح التطبيق بالكامل وتعمل حقول البحث وحسابات الشمس المحلية فوراً.
- **AC-2 (كاش المسارات المفتوحة Runtime Caching)**:
  - *Given* فتح مسار مسبقاً (مثل الدقي ➔ التجمع أو القاهرة ➔ إسكندرية).
  - *When* يتم طلبه أوفلاين.
  - *Then* يتم جلبه فوراً من `CacheStorage` مع شارة *"شغال أوفلاين ⚡"*.
- **AC-3 (ملف Manifest وتثبيت التطبيق)**:
  - *Given* متصفح يدعم الـ PWA.
  - *Then* تظهر أيقونة التطبيق واسمه "اقعد فين؟" مع دعم التثبيت على الشاشة الرئيسية لشاشات الموبايل.

---

## 3. مقتطفات المعمارية و Vite PWA (Dev Context)

```typescript
// vite.config.ts
import { VitePWA } from 'vite-plugin-pwa';

export default defineConfig({
  plugins: [
    VitePWA({
      registerType: 'autoUpdate',
      includeAssets: ['favicon.svg', 'data/places.json'],
      manifest: {
        name: 'اقعد فين؟ - دليل شمس المواصلات',
        short_name: 'اقعد فين؟',
        description: 'اعرف الكرسي والجنب المضلل في الميكروباص والأتوبيس في ثواني',
        theme_color: '#0EA5E9',
        background_color: '#F8FAFC',
        display: 'standalone',
        dir: 'rtl',
        lang: 'ar-EG'
      },
      workbox: {
        runtimeCaching: [
          {
            urlPattern: /\/data\/routes\/.*\.json$/,
            handler: 'CacheFirst',
            options: {
              cacheName: 'routes-cache',
              expiration: { maxEntries: 50, maxAgeSeconds: 30 * 24 * 60 * 60 }
            }
          }
        ]
      }
    })
  ]
});
```
