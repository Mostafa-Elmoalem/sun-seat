## 1. قصة المستخدم (User Story)
كراكب، أريد معرفة حالة الغيوم والسحب كمعلومة تكميلية مفيدة (عبر Open-Meteo المجاني بدون مفاتيح API) في `src/adapters/weather-service.ts` دون أن يعطل ذلك حساب الشمس الفلكي أو يؤخر ظهور القرار الحاسم إن تعثر أو تأخر الاتصال.

---

## 2. معايير القبول (Acceptance Criteria)

- **AC-1 (الاستدعاء غير المعطل Non-Blocking)**:
  - *Given* بدء حساب الرحلة.
  - *Then* تظهر النتيجة الأساسية فوراً؛ ويُطلب الطقس في الخلفية بشكل متوازٍ ومستقل.
- **AC-2 (مهلة زمنية صارمة Timeout 1.5s)**:
  - *Given* بطء في شبكة المحمول.
  - *When* يتجاوز استدعاء Open-Meteo مهلة **1.5 ثانية**.
  - *Then* يتم إسقاط الطلب وتجاهله دون إظهار أي رسالة خطأ مزعجة للمستخدم.
- **AC-3 (عرض شارة السحب التكميلية)**:
  - *Given* استجابة الطقس بنسبة غطاء سحابي (Cloud Cover $> 75\%$).
  - *Then* تظهر شارة خفيفة بجانب القرار: *"الجو مغيم جزئياً ⛅ (الشمس مش حامية أوي)"*.

---

## 3. مقتطفات المعمارية ودوال الخدمة (Dev Context)

```typescript
export async function getCloudCover(lat: number, lng: number, dateIso: string): Promise<number | null> {
  try {
    const url = `https://api.open-meteo.com/v1/forecast?latitude=${lat}&longitude=${lng}&hourly=cloudcover&forecast_days=2`;
    const res = await fetch(url, { signal: AbortSignal.timeout(1500) });
    if (!res.ok) return null;
    const data = await res.json();
    // استخراج نسبة الغيوم لأقرب ساعة
    return data.hourly.cloudcover[0] ?? null;
  } catch {
    return null; // فشل ناعم بدون أخطاء
  }
}
```
