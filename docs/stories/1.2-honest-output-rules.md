## 1. قصة المستخدم (User Story)
كراكب، أريد أن يقيّم المحرك حالة مسار الرحلة والشمس بدقة وأمانة علمية في `src/core/exposure/honest-rules.ts`، ليميز حالات الظلام التام ليلاً (Night)، وتعامد الشمس الصيفية الحارقة فوق سقف السيارة (Overhead Sun)، وحالات التعادل بين الجانبين (Tie)، حتى لا يعطيني التطبيق نصيحة وهمية مضللة.

---

## 2. معايير القبول (Acceptance Criteria)

- **AC-1 (حالة الليل التام - NIGHT)**:
  - *Given* رحلة تنطلق وتصل بعد الغروب وقبل الشروق (ارتفاع الشمس $\alpha < 0^\circ$ طوال المسار).
  - *When* يتم تقييم النتيجة بدالة `evaluateHonestRules`.
  - *Then* تُرجع الدالة حالة `NIGHT`، مع نسبة تعرض 0% للجانبين، وتحديد `winnerSide: null`.
- **AC-2 (حالة تعامد الشمس والظهيرة - OVERHEAD_SUN)**:
  - *Given* رحلة ظهيرة في الصيف بحيث يكون ارتفاع الشمس $\alpha > 68^\circ$ لأكثر من 70% من زمن الرحلة.
  - *When* يتم التقييم.
  - *Then* تُرجع الدالة حالة `OVERHEAD_SUN` وتوضح أن سقف السيارة هو الواقي الحقيقي وأن الجانب لا يشكل فارقاً.
- **AC-3 (حالة التعادل - TIE)**:
  - *Given* مسار طريق منحني تتساوى فيه نسبة التعرض للجانبين (الفارق $< 10\%$).
  - *When* يتم التقييم.
  - *Then* تُرجع الدالة حالة `TIE` وتوصي بحرية الاختيار.

## 3. مقتطفات المعمارية والنصوص (Dev Context)

### أ. كود ومنطق التحقق:
```typescript
export type HonestRuleResult = 
  | { type: 'NIGHT'; textAr: string }
  | { type: 'OVERHEAD_SUN'; textAr: string }
  | { type: 'TIE'; textAr: string }
  | { type: 'DETERMINISTIC'; winner: 'left' | 'right'; diff: number };

export function evaluateHonestRules(
  points: { elevation: number; relativeAngle: number }[],
  leftShade: number,
  rightShade: number
): HonestRuleResult {
  const isAllNight = points.every(p => p.elevation <= 0);
  if (isAllNight) return { type: 'NIGHT', textAr: "مفيش شمس.. اركب في أي حتة براحتك 🌙" };

  const highSunPoints = points.filter(p => p.elevation > 68).length;
  if (highSunPoints / points.length >= 0.7) {
    return { type: 'OVERHEAD_SUN', textAr: "الشمس فوق راسك بالظبط.. السقف حاميك ومش فارق الجنب ☀️" };
  }

  if (Math.abs(leftShade - rightShade) < 10) {
    return { type: 'TIE', textAr: "الجنبين زي بعض تقريباً.. اركب اللي يعجبك ⚖️" };
  }

  return {
    type: 'DETERMINISTIC',
    winner: leftShade > rightShade ? 'left' : 'right',
    diff: Math.abs(leftShade - rightShade)
  };
}
```
