## 2. معايير القبول (Acceptance Criteria)

- **AC-1 (حساب تعرض المقعد الفردي)**:
  - *Given* مسار مقسم زمنياً وموقع الشمس الفلكي عند كل لحظة.
  - *When* يتم حساب تقاطع شعاع الشمس مع نوافذ وسقف المركبة.
  - *Then* يحصل كل مقعد على رقم تعرض تراكمي من 0 إلى 100، وتكون المقاعد المجاورة للشباك المشمس أعلى تعرضاً دائماً من مقاعد الممر والمقاعد الوسطى.
- **AC-2 (حساب نسبة الظل الإجمالية لكل جانب)**:
  - *Given* قيم المقاعد.
  - *Then* يُحسب متوسط نسبة الظل للجانب الأيسر وللجانب الأيمن (مثلاً: 85% شمال مقابل 15% يمين).
- **AC-3 (تحليل الحساسية ومستوى الثقة)**:
  - *Given* الحسبة الأساسية عند التوقيت $T_0$.
  - *When* يُكرر الحساب عند $T_0 \pm 30\text{ min}$ وسرعة $\pm 20\%$.
  - *Then* إذا بقي الجانب الفائز ثابتاً بفارق $> 20\%$ في كل التجارب، يُصنف مستوى الثقة بـ "عالي جداً (HIGH)"؛ وإذا انقلب الجانب في سيناريو، يُصنف بـ "متوسط (MEDIUM)" مع تنبيه المستخدم.

## 3. مقتطفات المعمارية والمعادلات الرياضية (Dev Context)

// +x: يمين، -x: يسار، +y: للأمام، +z: لأعلى
const sunVector = {
  x: Math.cos(elevationRad) * Math.sin(relativeAngleRad),
  y: Math.cos(elevationRad) * Math.cos(relativeAngleRad),
  z: Math.sin(elevationRad)
};

// فحص حماية السقف:
if (elevationDeg > 68) {
  // السقف يحجب الشمس العمودية عن أغلب المقاعد
  return 0; // ظل تام
}

// تقاطع الشعاع العكسي مع الشباك x = ±width/2:
const t = (seatPos.x > 0 ? width/2 - seatPos.x : -width/2 - seatPos.x) / sunVector.x;
const zIntersect = seatPos.z + t * sunVector.z;
const isThroughWindow = zIntersect >= windowBottom && zIntersect <= windowTop;
