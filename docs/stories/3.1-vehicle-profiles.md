## 1. قصة المستخدم (User Story)
كمطور، أريد تعريف وسيلة النقل كملف بيانات وهيكل Schema مستقل في `src/core/vehicles/` يحدد أبعاد المركبة، معامل سرعتها بالنسبة للملاكي، مواقع النوافذ، ومواضع رؤوس الركاب ثلاثية الأبعاد $(x, y, z)$ لكل كرسي، لضمان استقلالية المحرك وإمكانية إضافة أي مركبة جديدة لاحقاً دون لمس كود الحسابات.

---

## 2. معايير القبول (Acceptance Criteria)

- **AC-1 (هيكل الميكروباص القياسي 14 راكب)**:
  - *Given* ملف تعريف `microbus-profile.ts`.
  - *Then* يحدد بدقة أبعاد التويوتا HiAce القياسية (طول 5.38م، عرض 1.88م، ارتفاع 2.28م).
  - *And* يحدد الكراسي الـ 14 موزعة على 4 صفوف بالإضافة لمقعد السائق والمقعد المجاور، مع تحديد دقيق لإحداثيات رأس الراكب $(x, y, z)$ حيث $x < 0$ لليسار و $x > 0$ لليمين.
  - *And* يحدد معامل سرعة واقعي `speedFactor: 1.15` وزمن توقفات `stopOverheadMin: 10`.
- **AC-2 (هيكل الأتوبيس الإقليمي 49 راكب)**:
  - *Given* ملف تعريف `bus-profile.ts`.
  - *Then* يحدد مقاعد الأتوبيس السياقي (سوپرجيت / جوباص) بترتيب صفين يميناً وصفين يساراً وممر في المنتصف.
- **AC-3 (التحقق الصارم من صحة النوع Schema Validation)**:
  - *Given* أي وسيلة نقل مسجلة.
  - *Then* تطابق واجهة `VehicleProfile` في TypeScript بشكل صارم.

## 3. مقتطفات المعمارية والـ Interface (Dev Context)

```typescript
export interface VehicleSeat {
  id: number;
  row: number;
  col: number;
  isWindow: boolean;
  side: 'left' | 'right' | 'middle';
  relativePos: {
    x: number; // بالمتر: سالب لليسار، موجب لليمين بالنسبة لمنتصف السيارة
    y: number; // بالمتر من مقدمة السيارة
    z: number; // الارتفاع عن الأرض
  };
}

export interface VehicleProfile {
  id: string;
  nameAr: string;
  speedFactor: number;
  stopOverheadMin: number;
  dimensions: { lengthM: number; widthM: number; heightM: number; roofOverhangM: number };
  windows: { side: 'left' | 'right' | 'front' | 'rear'; topM: number; bottomM: number; startM: number; endM: number }[];
  seats: VehicleSeat[];
}
```
